Register Biometric Device (ZKTeco)

Real-time sync – no records skipped: Not sure where to find the device serial or other details? See the "Where to get this information from your ZKTeco device" section below.

After registering, you will see a setup page with the exact push URL. Configure your ZKTeco device (e.g. ZKT Ecko, K40, C3-400) with that URL so each clock in/out is sent immediately. The app accepts JSON or tab-separated push format and normalizes punch types (0=Check In, 1=Check Out).
Push URL (set this in device firmware): {{ request.scheme }}://{{ request.get_host }}/api/biometric/push

In device firmware: Enter the same Device Serial and Device Secret as below. The device authenticates via X-Device-Secret header or device_secret in the body. Serial can be sent in body, X-Device-Serial header, or SN query param.

Employee mapping: In Employees, set each employee’s Biometric UID to match the user ID/PIN the device sends (e.g. PIN or user_id). Unmapped punches are stored for audit but not shown in attendance.

Where to get this information from your ZKTeco device
Form field How to get it from your office ZKTeco device
Device name Choose any name (e.g. "Reception", "Main Gate"). Not read from the device.
Device serial On the device: Menu → Device Info / System Info / About → look for Serial Number or SN. Copy it exactly (numbers and letters).
Via PC software: Open ZKAccess or ZKBioAccess → connect to the device → Device Management / Device Info → Serial No.
Via web: If the device has a web interface, open http://<device-IP> in a browser → Device / System Info → Serial Number.
Device IP On the device: Menu → Network / TCP/IP → IP Address (e.g. 192.168.1.100). Optional: leave blank if you only use push (device sends to this app).
Device port ZKTeco default is 4370. On device: Menu → Network → Port. Usually leave as 4370 unless you changed it.
Device secret You choose this value: it must be the same in the registration form and in the device.
Step 1: Type a strong password here (e.g. a random string).
Step 2: On the device (or in ZKAccess): find Push URL / Webhook / HTTP Push / Real-Time Push settings → set Secret or Token or API Key to the exact same value. The device will send this when pushing attendance.
Device model / Location Optional. Model is often on a label on the device (e.g. ZKT Ecko, K40). Location is for your reference (e.g. "Ground floor").

After saving: Use the setup page to set the Push URL in the device (same place where you set the Secret). Then the device and app will stay in sync.
