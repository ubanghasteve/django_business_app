About Session Tracking:
  • Each login creates a unique session - even if using the same account from multiple devices
  • The IP Address column shows the actual network IP of each device at the time of login
  • Mobile devices show their cellular/WiFi network IP, desktops show their network's public IP
  • Login Time is recorded when the user signs in, Logout Time when they sign out
