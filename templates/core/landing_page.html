Install City Prints
Choose your device for step-by-step instructions
City Prints looks installed on this device. Browsers cannot delete or replace an installed app automatically (for security). Use the Reinstall tab to remove the old one, then install again.

Best with Chrome on Android.

  1. Open this website in the Chrome browser.
  2. Tap the ⋮ menu (three dots) at the top right.
  3. Tap Install app or Add to Home screen.
  4. Confirm by tapping Install or Add.
  5. Find the City Prints icon on your home screen and open it like a normal app.
If you don’t see Install, the app may already be installed — open the Reinstall tab.

Use Safari on iPhone or iPad (most reliable).

  1. Open this website in Safari (not Chrome if possible).
  2. Tap the Share button (square with an upward arrow).
  3. Scroll and tap Add to Home Screen.
  4. Edit the name if you want, then tap Add.
  5. Open City Prints from your Home Screen.
Apple does not show a browser “Install” button. Share → Add to Home Screen is the correct way.

Works best in Chrome or Microsoft Edge.

  1. Open this website in Chrome or Edge.
  2. Look in the address bar for an install / app icon and click it, or open the browser menu (⋯).
  3. Chrome: go to Cast, save and share (or Save and share) → Install page as app.
  4. Edge: go to More tools → Apps → Install this site as an app.
  5. Click Install. The app opens in its own window and can be pinned to Start or the taskbar.
If Install is missing, City Prints is probably already installed — use the Reinstall tab.

You can use Safari, Chrome, or Edge.

  1. Safari: open this site, then choose File → Add to Dock….
  2. Chrome / Edge: open this site, click ⋯, then choose Install page as app / Install this site as an app.
  3. Confirm Install or Add.
  4. Launch City Prints from the Dock, Launchpad, or Applications.
For the most app-like experience on Mac, Chrome or Edge “Install as app” is usually best.

Websites cannot uninstall or overwrite an installed app by themselves. Remove the old City Prints app first, then install again for a fresh copy (new icon, settings, etc.).

Windows (Edge / Chrome)

  1. In Edge open edge://apps (or in Chrome open chrome://apps).
  2. Find City Prints → open details / ⋮ → Uninstall.
  3. Confirm uninstall (you can also remove it from Windows Settings → Apps).
  4. Return to this website, refresh, then install again from the browser menu.

Android (Chrome)

  1. Long-press the City Prints icon on your home screen or app drawer.
  2. Tap Uninstall / Remove (or App info → Uninstall).
  3. Open this site in Chrome again and use Install app.

iPhone / iPad

  1. Long-press the Home Screen icon → Remove App → Delete App (or Remove from Home Screen).
  2. Open the site in Safari → Share → Add to Home Screen again.

Mac

  1. Chrome/Edge: uninstall from the browser’s Apps page, or move the app from Applications to Trash.
  2. Safari Dock app: right-click the Dock icon → Options → Remove from Dock (and delete the app if listed in Applications).
  3. Open this site again and install / Add to Dock.
Day-to-day updates (bug fixes, new pages) usually apply automatically via the service worker — you only need to reinstall for a full reset or when the desktop icon does not refresh.
